# Feline Fanatics

A cat-lover community landing page built as part of [The Odin Project](https://www.theodinproject.com/) Foundations curriculum.

## Features

- Responsive hero section with a call-to-action
- Community feature cards with cat photography
- Quote section and signup banner
- Mobile-friendly layout

## Built With

- HTML5
- CSS3
- Roboto from Google Fonts

## Project Structure

```text
.
├── index.html       # Main page markup
├── styles.css       # Page styling and responsive rules
├── assets/          # Cat images used throughout the page
└── design/          # Design brief and reference materials
```

## Preview Locally

Open `index.html` directly in a browser, or serve the project with a local web server:

```bash
python3 -m http.server
```

Then visit <http://localhost:8000>.
